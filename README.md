# ☕ sipNGo - Coffee & Tea Ordering App

A multi-platform mobile and web application for quick coffee and tea ordering.

## Features
- Menu browsing for Coffee, Tea, and Beverages
- Drink customization (Size, Milk, Sugar)
- Real-time shopping cart tracking
- Seamless mobile and web layout

## Tech Stack
- **Frontend:** React Native / Expo
- **Database & Auth:** Firebase / Supabase (Planned)
- **Payments:** Stripe API (Planned)
