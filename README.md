A cross-platform mobile and web application for seamless coffee, tea, and pastry ordering with real-time order tracking and barista updates.
# ☕ Coffee & Beverage Ordering App

A modern, fast, multi-platform mobile (iOS/Android) and web application designed to streamline cafe ordering. Customers can customize their drinks, pay securely, and track their orders in real-time, while baristas receive immediate incoming ticket updates.

---

## ✨ Features

### 🛒 Customer App (Mobile & Web)
* **Custom Drink Builder:** Choose size, milk alternatives, sugar level, temperature, and add-ons.
* **Seamless Checkout:** Integrated secure payment processing (Apple Pay, Google Pay, Credit/Debit cards).
* **Real-time Order Status:** Live progress updates from *Received* ➔ *Preparing* ➔ *Ready for Pickup*.
* **Quick Reorder:** Save favorite drinks and past orders for 1-tap reordering.

### ☕ Barista / Store Dashboard (Web Tablet View)
* **Live Order Queue:** Real-time incoming tickets with visual and audio alerts.
* **Order Management:** Update order status with one tap.
* **Stock Controls:** Toggle item availability (e.g., mark ingredients out-of-stock instantly).

---

## 🛠️ Tech Stack

* **Frontend:** Flutter / React Native (Cross-platform for iOS, Android, and Web)
* **Backend & Database:** Firebase / Supabase (Real-time database, Auth, Cloud Storage)
* **Payments:** Stripe API / Apple Pay / Google Pay
* **Hosting:** Vercel / Netlify (Web)
